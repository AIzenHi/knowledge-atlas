把线性代数拖成看得见的样子

线性代数不是一堆符号，它其实在描述一件事：空间怎么被拉伸、旋转、压缩、投影。下面每个模块都可以动手玩——拖点、拖滑块、看图形变形。

01

向量 · 内积 · 投影

拖动红色 a 和蓝色 b 的端点

内积不是神秘东西：a·b 就是把 b 在 a 方向上的影子长度，乘上 a 的长度。它同时也是 |a||b|cosθ，所以内积 = 投影 × 缩放。
关键直觉：绿色是 b 在 a 上的投影，黄色是"投影剩下的部分"。注意黄色永远垂直于 a —— 这就是勾股定理，也是后面所有正交分解的根。黄色描边的平行四边形，它的面积 = |a×b| = |a||b|·sinθ（θ=90° 时面积最大）；而 |a·b| = |a||b|·cosθ（θ=90° 时恰好为 0）。一个管面积、一个管投影——行列式管的正是前一个，这就是它几何意义的小预告。顺带一提：a = (1.70, 1.10) 这两个数字，是 a 相对于标准基 e₁, e₂ 的坐标。换个基，数字就变、位置不变——这是下一模块的全部内容。
02

基与坐标 · 张成空间

绿色 u、紫色 v 是"基"，拖粉色点 P 看它在新坐标系里的位置

换个基，同一个点的数字就变了。但几何位置纹丝不动——矩阵 B 把新坐标转回老坐标，B⁻¹ 反着来。基选得好 = 数字好看且互不干扰。
关键直觉：点一下"共线"，你看 det→0，坐标系直接塌成一条线。此时方程 B·x=P 只有两种结局：P 恰好落在这条线上 → 无穷多个解（给 x 随便加几个 u 的倍数都行）；P 离线而去 → 一个解也没有（黄色那段垂距就是够不着的部分）。基的定义就是"不塌"：线性无关。面积 = |det| 是坐标系有多"正"的体检指标。
03

正交化 · QR 分解

拖动两个向量，看 Gram-Schmidt 一刀切掉"重复信息"

为什么要正交化？两个斜着的向量很难分别"看出"各自贡献；掰直之后，投影 = 除以长度，正交投影、退化最小二乘全部变成除法。正交基 = 互不干扰的坐标系。
关键直觉：面积完全没变（|u×v| = |w₁||w₂| —— 因为掰直之后 w₁⊥w₂，|w₁||w₂| 就等于平行四边形的面积）—— 我们只是把斜的坐标系掰直，没有压扁也没有拉长。这个"掰直不改变体积"的分解，就是数值计算里最常用的 A = QR，其中 A = [u v]（u 和 v 摆成两列）。

关键直觉：矩阵的列就是新基向量，矩阵乘法就是"把每个向量按新基重新组装"。det<0 镜像（左右手对调），det=0 压扁成一条线（信息永久丢失、不可逆），|det| 就是面积放大倍数。每一列都是 A 作用在某个基向量上的结果——所以"矩阵乘法"和"按新基重新组装"是同一件事的两种说法，03 的 QR 就是在给这个新基做体检。

关键直觉：当特征值是实数时，任意向量迭代足够多次都会"跑偏"到模最大的那个特征值对应的方向上去（主方向）。特征向量是 A 的偏好：|λ|>1 优先放大，|λ|<1 收缩，λ<0 还会掉头。对角化 = 换到偏好方向，变换立刻变简单。（若 λ 是复数，则没有任何实特征方向，向量会一直转下去——见右侧读数。）λ 从哪来？解方程 det(A − λI) = 0。拖滑块时盯住 det(A − λI)：它恰好过零的那些 λ，就是特征值。

07

最小二乘 = 把点投影到一条线上

上下拖动任意数据点，拟合线会自动跟着动

为什么最优？把 n 个数据点看成 ℝⁿ 里的两个向量：1 = (1,1,…,1) 和 x = (x₁,…,xₙ)。拟合值 a+bx 就是 y 在 span{1, x} 上的正交投影，所以残差 r 必然同时垂直于 1 和 x：Σrᵢ = 0（不高估也不低估）且 Σxᵢrᵢ = 0（与自变量无关）。记住 {1, x} 活在 ℝⁿ 里，不是图上那条线——在 (x, y) 平面里任何直线都能写成 y=a+bx，那个空间就是整个平面。
关键直觉：先点"加个弯曲趋势"——残差会排成漂亮的 U 形：中间几个点一致在线上方（+残差），两头一致在线下方（−残差）。这不是随机噪声，而是一个系统性的弯曲趋势。这叫有偏：数据是弯的，直线怎么摆都摆不平。但请注意右侧 Σr = 0 和 Σxᵢrᵢ = 0 依然同时归零——有偏 ≠ 不最优。最优性只要求残差和两个方向垂直，它从不要求数据本身是直的。再勾上"强制过原点"：b 被钉死在 0，模型少了一个自由度，残差仍然和 x 正交，但再也不能和全 1 向量正交（Σr ≠ 0）——这不是"最优性失效"，是"最优的方向变了"。点一下数据点把残差线拉长或缩短试试：最优解会自动挪一点去补偿，但永远补不平。

术语速查

十五个概念，一句话版本

向量空间

一组"向量 + 加法 + 数乘"的集合，能像坐标一样加减缩放。R²、R³、矩阵集合、函数集合都是。

线性相关

存在一组不全为零的系数 c₁…cₙ，使 c₁v₁ + … + cₙvₙ = 0。这样的组合存在 ⇒ 线性相关（至少有一个向量是多余的）；不存在 ⇒ 线性无关（谁也删不掉）。注意：相关说的是"能不能凑出 0"，不是"能不能凑出别人"。

基 / 张成

一组既能撑起整个空间、又互不冗余的向量。张成的空间维度 = rank。

线性变换

"直线进、直线出"的映射，全部由一个矩阵刻画。保持加法和数乘是它的定义。

行列式 det

有向面积缩放倍数。det=0 → 压扁、信息丢失、不可逆；det<0 → 镜像。

零空间 / 列空间

被压成 0 的方向 vs. A 能造出的所有结果。Ax=b 有解 ⇔ b ∈ 列空间。

正交 / 内积

垂直叫正交。内积给出长度、角度、投影，是几何得以进入代数的大门。

特征值 λ / 特征向量 v

Av = λv：这个特殊方向只被拉伸 λ 倍。λ 描述"变化的速度与方向"。

秩 rank

矩阵真正"有效"的自由度个数。rank=满 → 可逆；rank=1 → 只剩一条线。

正交投影

空间某点到子空间的最短连线，永远垂直。把复杂问题"拍平"成简单的。

QR / LU 分解

把难算的变换拆成简单步骤的"食谱"。QR：A = QR，Q 的列正交（互相不干扰），R 是上三角；"掰直坐标系不改变体积"。LU（本页未展开）：把 A 拆成下三角×上三角，对应高斯消元的行阶梯形。

条件数 κ

变换有多"娇气"：κ = σ₁/σ₂，是"放大得最多的方向"和"压缩得最狠的方向"的比值。κ = 1 表示所有方向被拉长/压缩得一样多（角度不失真，比如镜像 diag(1,−1) 的 κ 就是 1）；κ → ∞ 表示某个方向被压成 0（奇异）。κ 与"矩阵长什么样"无关，只与它有多接近压扁有关。

迹 tr(A)

所有特征值之和 = 主对角元之和。tr(A) = Σλᵢ，det(A) = λ₁λ₂。

子空间

空间里的一片平面，本身就是一个向量空间。列空间、零空间、正交补都是子空间。

代数重数 / 几何重数

λ 在 det(A−λI) 里出现的次数 / 对应的独立特征向量个数。两者相等 ⇒ 能对角化；不等 ⇒ 不能（例如 [[2,1],[0,2]]，λ=2 出现两次但只有一个特征方向）。
