① 认识敌人 · 黑天鹅

世界比你想象的更「胖」

你以为极端事件是十亿分之一的奇迹？在肥尾世界里，它可能年年上新闻。先学会分辨：你活在哪一种世界里。

🦃 火鸡的 1000 天

火鸡被连续喂了 1000 天，它「验证」出人类是善良的。第 1001 天是感恩节。
稳定持续得越久，越要问：我的「1000 天」会不会藏着一个第 1001 天？

🎯 黑天鹅三件套

① 极其罕见：超出常规预期
② 冲击巨大：能改写总量
③ 事后可解释：人人都像早就知道

⚖️ 两种世界

温和世界（正态）：极端事件的概率像跳崖一样塌缩。
极端世界（幂律）：极端事件「罕见但不见外」，而且一次能抵十次用。

📐 数学小抄

正态尾部：P(X > x) ≈ e−x²/2 —— 指数级塌缩，6σ 约等于「十亿分之一」
幂律尾部：P(X > x) ∝ x−α —— 幂级减速，6 倍事件还有 6−α 的概率
α ≤ 2 → 方差无穷大；α ≤ 1 → 均值无穷大（历史平均值自己都不收敛）
最大值法则：n 个样本里的最大值量级 ~ n1/α —— 样本翻 100 倍，最大值只翻 1001/α 倍
深入一层：为什么肥尾世界里的「平均值」靠不住？

因为样本均值由最大值主导：在 α=1.5 时，1000 个样本里最大的那个大约占总和的很大一块，而且这个「最大」本身会随样本数缓慢增长（~n1/α）。你永远在等待还没出现的最大样本——所以均值估计永远偏低，方差永远低估。传统统计的「样本够多就收敛」在这里失效。

⚠️ 常见误解：「历史上没发生过 = 不可能发生」；「数据够多就能估准风险」。在肥尾世界里，样本均值会跟着最大的一两个样本到处乱跑。

② 转变姿态 · 反脆弱

波动是燃料，前提是你的曲线向上弯

同样一场风波，有人被拍进土里，有人越打越强。区别不在运气，在收益曲线的形状：凹的怕波动，凸的爱波动。

🧊 脆弱（凹）

玻璃杯、满仓杠杆、「一次定终身」。波动一来就碎，且碎了不能复原——曲线向下弯。

🪨 坚韧（线性）

石头、分散的现金、结实的系统。摔一下还是石头，但也仅此而已——波动不会让你更好。

💪 反脆弱（凸）

肌肉、免疫系统、九头蛇、期权、一串小赌注。冲击来了不但不死，还把冲击吃成营养——曲线向上弯。

🧪 实验室 2 · 曲率调节器先拖曲率 k，再拖波动 σ

k > 1 向上弯（凸、反脆弱）｜k = 1 直线（坚韧）｜k < 1 向下弯（凹、脆弱）——试试两极：k=0.1 是「玻璃杯」，k=3 是「超级肌肉」。

σ = 0 时没有波动，凹凸看不出差别——波动是暴露曲率的显影液。

每个圆点 = 某次冲击落在曲线上的结果；所有冲击的平均固定为 μ = 1。

📐 数学小抄

二阶泰勒：E[f(X)] ≈ f(μ) + ½·f″(μ)·σ² —— 波动 × 曲率 = 额外收益（或损失）
琴生不等式（Jensen）：f 凸 → E[f(X)] ≥ f(E[X])；f 凹 → E[f(X)] ≤ f(E[X])
凸性的现实别名：可选性（optionality）——损失封顶、收益开口
深入一层：为什么「波动 × 曲率」是最重要的一句话？

把 f 在均值 μ 处做泰勒展开并取期望：一次项期望为零（波动是零均值的），剩下的第一项就是 ½·f″(μ)·σ²。这意味着：你既不需要预测波动的方向，也不需要预测它的时间——只要 f″ > 0（凸）且 σ 存在，波动本身就贡献正收益。这就是「反脆弱」的全部数学。

⚠️ 常见误解：「稳定压倒一切」——稳定对脆弱系统是续命，对反脆弱系统是扼杀。先分清你手里的是玻璃杯还是肌肉。

③ 摆好阵型 · 杠铃策略

90% 极度安全 + 10% 极度激进，中间是陷阱

如果左尾能保命、右尾能翻身，那为什么只要一头？塔勒布的答案：两头都要，中间不要。

直觉：把资金切成两段——大头放在「无聊到不会死」的地方（现金、国债），小头押在「输了不心疼、赢了一辈子」的凸性机会上。组合的下限被安全垫钉死，上限交给小注去博。
最惨的是中间档「中庸配置」：黑天鹅来了它也腰斩，行情来了它也涨不到天上去。

深入一层：为什么「中庸资产」比想象中脆弱？

中风险资产（企业债、混合基金、加杠杆的「稳健理财」）看上去波动温和，但它们内嵌了期限错配和隐性杠杆，且左尾是「断崖」式的（信用事件、挤兑、流动性消失）。平时它们用小波动给你发糖，黑天鹅来临时把几年的糖一次性收走——收益有顶、损失没底，正是杠铃要绕开的那一段。

⚠️ 常见误解：「杠铃 = 激进」——恰恰相反，它第一条军规是「无论如何别死」；「随便买点彩票就行」——要的是损失有界、收益开口的凸性押注，而不是纯负期望的消费。

④ 下注尺寸 · 凯利公式

赌得对，还要下得「刚刚好」

优势再大，下注太大也会破产。凯利算的不是赚最多的比例，而是「活得最久、滚得最快」的比例——长期复利增长的最优解。

🐢 下太小

优势被浪费，雪球滚得像散步。安全，但你在用速度换心安。

🐇 下太大

哪怕赌局对你有利，波动也会先把你洗出局。双倍凯利的长期中位数，约等于原地踏步。

🎯 刚刚好

f* 位置：每局对数增长最大。现实中 p 靠估计 → 高手默认再打个折（半凯利）。

🧪 实验室 4B · 三档下注模拟300 局 × 200 条命，同场竞技
🌿 半凯利 f*/2
🎯 全凯利 f*
🔥 双倍凯利 2f*

盯住双倍凯利：中位数贴地飞行（每局对数增长为负），深水概率却一路飙升——这就是「过度下注」的数学死刑。胜率越高、赔率越好，越要警惕手痒；现实中 p 是估出来的，所以老手常用半凯利。

📐 数学小抄

凯利比例：f* = (b·p − q) / b = p − q/b（q = 1−p）
对数增长率：G(f) = p·ln(1+b·f) + q·ln(1−f)，f* 处取最大值
本金翻倍局数 ≈ ln 2 / G(f*) ｜ 前提：赌局可重复、概率稳定、p 不会偷偷变
深入一层：f* 是怎么推出来的？（两行微积分）

求导：G′(f) = p·b/(1+bf) − q/(1−f) = 0 → 解出 f* = (bp − q)/b。
二阶导 G″(f) = −p·b²/(1+bf)² − q/(1−f)² < 0 恒成立，所以 f* 是唯一的全局最大值——这就是「双倍凯利为什么惨」的数学根源：对称地远离极大值，左半边增长变慢，右半边直接滑向负增长。
顺带一提：q/b 就是「赔率对胜率的要求」，f* > 0 等价于 p·b > q，即赌局有正期望。

⚠️ 常见误解：「胜率 90% 就该下 90%」——赔率同样决定 f*；「凯利教你收益最大化」——它最大化的是长期几何增长率，为此宁愿放慢一点速度，换取「永不归零」。

⑤ 边玩边学 · 多臂老虎机

胜率未知时，先把「试探」当成投资

现实里没人告诉你 p。于是问题变成：先拉哪台？拉几次？什么时候换台？——这就是探索与利用的权衡。

想象面前 4 台老虎机，胜率各不相同但你不知道。每拉一次都在花掉一次机会：试冷门臂 = 交学费换信息，拉熟悉的臂 = 兑现已知收益。纯贪心会卡在第一次的好运上；纯探索永远在交学费。UCB 给「不确定性」标了价，汤普森让你按「当前相信的程度」掷骰子——都在做同一件事：让错过的好运（遗憾）增长得尽可能慢。

📐 数学小抄

遗憾（Regret）：RT = Σt ( μ* − μ(at) ) ——「错过的最优收益」的累计
UCB1：选 argmax( x̄i + √(2 ln t / ni) ) —— 均值 + 不确定性奖金
汤普森采样：给每臂维护 Beta(赢+1, 输+1) 后验，按后验随机采样选臂
已知最优下界：遗憾至少按 log T 增长；优秀算法的遗憾上界也接近它——「学习」是支付得起学费的
深入一层：UCB 的「不确定性奖金」在说什么？

x̄i + √(2 ln t / ni)：均值部分是「现在看起来多好」，根号部分是「我还多不了解它」——拉得越少的臂，奖金越高；回合 t 越大，奖金整体缓慢缩水。所以 UCB 从不「永久放弃」任何一条臂，只是把好奇心的预算越收越紧。
汤普森采样换了个视角：不确定 = 后验分布很宽，掷骰子时偶尔会掷出乐观值，于是自动多试；信念收窄后，探索自动减少。两种算法都在回答同一个问题：好奇心值多少钱？

⚠️ 常见误解：「先测到显著，再全量押注」——中规中矩，但会把大量流量浪费在差臂上；老虎机思路是边测边赢。另一个误解：「贪心最快」——它只是最快锁死错误答案。

⑥ 保底思维 · Minimax（最小最大）

当概率不可信，先算最坏情况

老虎机要你相信 p，凯利要你估计 p——可现实里没人给你发 p。Minimax 的回答硬核又诚实：不猜概率，只求「最坏情况里最好的那条路」。

🎯 一句话思想

对每个选择，先问「最坏会怎样」，然后选那个最坏结果里最好的（max-min）。悲观，但保底。

⚔️ 零和博弈

你赢多少＝对手输多少。冯·诺依曼定理：混合策略下，你的 max-min ＝ 对手的 min-max——存在唯一的博弈值。

🧭 什么时候用

对手聪明、概率没谱、后果要命：谈判、竞争、军事、保命钱、鲁棒设计。期望值赌「平均」，minimax 保「下限」。

📐 数学小抄

零和博弈：收益矩阵 A（你选行、对手选列；一方所得＝另一方所失）
你的保底：v⁻ = maxp minq E(p,q) ——「最坏里最好的」
对手的压制：v⁺ = minq maxp E(p,q) ——「你最好时他能按住的最狠」
冯·诺依曼 minimax 定理：v⁻ = v⁺ = v（混合策略下必相等）
深入一层：为什么「混合」比「硬刚」强这么多？

纯选 T：对手全选 R，你的保底是 0；纯选 B：对手全选 L，保底还是 0。
但按 25% / 75% 混合：对手全选 L 你拿到 3p=0.75，对手全选 R 你拿到 1−p=0.75——两条路都堵不死你。几何上，这正是「对手两条纯策略线的交点」。
顺带一提：minimax 的代价是放弃更高的平均值（对手要是很菜，你本可以多赚）。它买的不是收益，是绝对下限——这正好接上凯利那条线：可重复、概率可信 → 博长期增长；不可重复、概率不可信 → 先保下限。

⚠️ 常见误解：「minimax 太怂」——它是保底最优，先把最坏情况钉死再谈别的；「max-min 和 min-max 可以随便换」——顺序不同含义完全不同：前者是你的保底，后者是对手的压制。

黑天鹅 极端事件罕见但能改写一切。先分辨你活在正态世界还是肥尾世界。 P(X > x) ∝ x−α；α 越小尾巴越肥，「均值」越不可信。 评估风险、配置资产、读历史数据、评估「这次不一样」的时候。
反脆弱 波动对凸曲线是燃料，对凹曲线是税收。先看清自己曲线的形状。 E[f(X)] ≈ f(μ) + ½·f″(μ)·σ²：波动 × 曲率 = 漂移。 设计策略、制度、职业路径时——把自己摆到凸的一侧。
杠铃策略 90% 极度安全 + 10% 极度激进，跳过「中等风险」的温柔陷阱。 损失有底（约 −(1−w)）、收益无顶；两端都极端。 面对黑天鹅风险又不想错过机会：配置资产、组合副业、规划人生。
凯利公式 有优势时，下注尺寸比方向更重要：太大破产、太小浪费。 f* = p − q/b；G(f) = p·ln(1+bf) + q·ln(1−f)；实际用半凯利。 可重复、概率可估、赔率清晰的下注场景：投资、谈判、决策。
多臂老虎机 胜率未知时，用算法平衡「试探」和「收割」，让遗憾增长最慢。 UCB：均值 + √(2 ln t / n)；汤普森：Beta 后验采样。 A/B 测试、广告预算分配、临床试验、推荐系统、职业试错。
Minimax 概率不可信时，不赌平均、只保下限：选「最坏里最好」的那条路。 v⁻ = maxp minq E(p,q) = minq maxp E(p,q)（混合策略下相等） 对手聪明、概率没谱、输不起：谈判、竞争、军事、保命钱、鲁棒设计。

💼 职业组合拳

白天一份稳定工作 = 安全垫；晚上小成本试错副业 = 小注。别蒙眼辞职 all-in，也别在一个岗位上「稳定」到火鸡的第 1000 天。

📈 投资组合拳

现金/国债打底 + 损失有界、收益开口的凸性小仓（期权、早期项目、你自己的手艺）。让无聊的部分负责活着，让疯狂的部分负责活着有盼头。

🧠 学习组合拳

核心技能练到不漏水 + 广泛低成本试错新方向。注意力也是一种赌注：大部分押在基本盘，一小部分押在可能性。
