🧭 先建一张心智地图

微积分只有两个核心动作，其余全是它们的组合拳。

🔬 局部动作：导数 微分

把镜头怼到某一点上，问：此刻变化有多快、朝哪个方向？
数学形式：f′(x) = limh→0 f(x+h) − f(x)h， 几何意义：切线的斜率。物理意义：瞬时速度 / 瞬时加速度。

🌊 整体动作：积分 求和

把镜头拉远，问：这么一点点变化，攒起来一整段是多少？
数学形式：∫ab f(x) dx， 几何意义：曲线下的面积（可正可负，所以叫"有向面积"）。物理意义：总累积量。

🌉 连接它们的桥：极限

局部和整体之间必须有"无限逼近"的严格地基，否则就只是图形直觉。
极限是唯一允许"除以 0""取无穷"还仍然合法的通道。

一句话记住： 导数是"这一瞬间的快"，积分是"这一整段时间的总"。 两者互为逆运算，就像乘法和除法、平方和开方一样——这就是下面第 ⑥ 站要亲手验证的东西。
① 速度 → 位置（导数）
给你每时刻的速度，想知道走了多远 → 积分。汽车仪表盘是导数，里程表是积分。

② 面积 → 高度的变化率（微积分基本定理）
"水位涨得有多快"＝"此刻的进水速度"。这一条把上面两个动作焊死成一体，是整个微积分的枢纽。

③ 微分方程：规则的数学表达
牛顿 F=ma 写成 dx/dt = v，再积分回去就得到 x(t) = ½at²。物理、工程、经济里 90% 的模型最后都长这样。

① 极限：为什么能除以 0 还能得到数？

拖动滑块让 h 一路逼近 0，看函数值乖乖地聚到某一点。

💡 拖动 h 滑块时注意看：函数值一直在变，但你和极限点的距离一直在缩小——这就是极限的全部含义，它只关心"趋势"，不关心"取到没有"。

ε-δ 定义（唯一需要背的）： limx→a f(x) = L ⟺ 对任意 ε>0，都能找到 δ>0，使得只要 0 < |x − a| < δ，就一定有 |f(x) − L| < ε。
翻译成人话："你把 x 拿得足够靠近 a，我就保证 f(x) 落在 L 附近那个小圈里。"注意 f(a) 本身是什么完全无关——所以 1/x 在 x=0 处没定义，但它的极限却可能存在。

② 导数：割线怎么变成切线？

这是整门课最该动手玩 10 分钟的地方。割线的一端死死钉住，另一端慢慢靠近。

割线长度 h割线斜率 f(a+h) − f(a)h与真实导数的差状态

🖱️ 也可以直接在图上拖动那个实心圆点来改变 a。拖到 |x| 的拐角处，会看到左右斜率打架——这就是"不可导"。

为什么必须"极限"而不是"真的取 h=0"？ 因为 f(a+h) − f(a)h 的分子里同时有 +f(a) 和 −f(a)，h=0 时上下都变 0，直接代就得到 0/0。 所以导数的定义必须写成"极限"，它是一句条件性的话：只要 h 无限小且不等于 0，这个式子就趋近某个数。这也解释了为什么 |x| 在 0 处导数不存在——左右两个 h 的走向给出了不同的极限。

③ 求导规则实验室：原函数和导函数长什么样

蓝色实线是原函数 f，红色虚线是它的导函数 f′。切线斜率 = 虚线在该点的高度。

规则公式一句话理解
常数倍(cf)′ = cf′放大曲线 f 倍，斜率也放大 f 倍
和差(f ± g)′ = f′ ± g′两条曲线叠起来，斜率也跟着叠加
乘积(fg)′ = f′g + fg′两人抬轿：谁在使劲，斜率就含谁
商(f/g)′ = (f′g − fg′)/g²先变分子减去分母"自己变"，要除两次分母
链式(f∘g)′ = f′(g(x))·g′(x)转两道弯，速度是两层速度相乘（见第 ⑦ 站）
反函数(f⁻¹)′(y) = 1 / f′(f⁻¹(y))两条曲线关于 y=x 对称，斜率互为倒数
幂函数(xᵖ)′ = p·xp−1指数变成系数，次数减一
指数(ex)′ = ex, (ax)′ = axln ae 的魔力：它的变化率等于自己
对数(ln x)′ = 1/x, (logax)′ = 1/(x ln a)ln 与指数互为逆函数，斜率互为倒数
三角(sin x)′ = cos x, (cos x)′ = −sin x摆动 ↔ 倾斜互相转换，tan 则是两者相乘
一条能省命的线索： 上面 10 条规则几乎都能从 ①乘积法则 和 ②链式法则 推出来。所以真正需要硬记的只有"基本函数求导值"这一张表， 剩下的都是拼装。先背基本表，再练拼装，比硬背 15 条公式效率高得多。

④ 泰勒展开：用直线和曲线拼出整个函数

拖阶数 n，看红点区域（余项）如何被一项项吃掉。

泰勒是"用局部信息重建整体"： f(x) = f(a) + f′(a)(x−a) + f″(a)}{span>2!(x−a)² + …
一阶项是切线，二阶项是"弯曲的修正"，三阶项是"扭曲的修正"……n 阶就是前 n 层修正。 实用价值：e、sin 1、ln 2、π 这些"算不出来"的数， 牛顿就是靠它在纸上算出来的；今天的科学计算、误差估计、ODE 数值解也还靠它。

⑤ 积分：把无限多个矩形塞进曲线里

拖 n（分割数）看矩形怎么变细逼近面积，同时左边表格里的和怎么撞上真值。

n近似值 Sn真值（精确到小数点后 6 位）绝对误差相对误差
定积分的严格定义： ∫ab f(x)dx = limn→∞ Σk=1n f(xk)·Δx， 其中 Δx = (b−a)/n。
关键：左端点和右端点的和都趋近同一个数（就像 ∫ 的加法性质保证的那样），只有取点方式会影响速度， 不影响终点。这正是"面积"能脱离"点"而客观存在的原因。
注意"左和 < 真值 < 右和"： 对递增函数，左端点矩形永远偏小、右端点永远偏大。中间点、梯形、辛普森误差衰减得快得多 （辛普森是 O(1/n⁴)，是左端点的 O(1/n) 的四倍效率）—— 这就是数值积分软件的默认算法选择逻辑。

⑥ 微积分基本定理：导数和积分原来是同一件事

拖动上限 x：上面是"注水速率"，下面是"水位"。看下面那条切线的斜率。

生活类比：水箱注水
f(t) = 现在的进水速度（L/分钟，可能为负表示在漏水）→ 这是导数的世界。
F(x) = ∫0x f(t)dt = 到此刻为止一共进了多少水（水位）→ 这是积分的世界。
结论：水位此刻的上升速度，恰好等于此刻的进水速度。也就是 F′(x) = f(x)。 微积分 2000 年来最深刻的一句话，就是"累积量和变化率互为逆运算"。

⑦ 链式法则：为什么速度要相乘？

两层嵌套函数，各自的速度乘起来就是复合函数的速度。

机械传动比： 想象 x 是主动轮的转速，它先经过齿轮组变成 u = g(x)， u 再驱动一台输出机得到 y = f(u)。
主动轮加速 → 中间轮加速 → 输出跟着加速。总传动比 = 中间轮比 × 输出机比 = g′(x) × f′(u)。 如果中间轮会反向（g′<0）或空转（f′=0），输出就减速、翻转或停摆—— 中间任一环为 0，整条链速度为 0，这正是链式法则在物理上的意义。

⑧ 常见陷阱与易混概念

这些坑几乎每个人都会踩一遍，提前知道能省一周时间。

坑错误想法正确理解
把极限当代入lim f(x) 就是 f(极限点)完全错误。1/x 在 0 无定义，但 lim(x→0)1/x 不存在；(x²−1)/(x−1) 在 1 无定义，但极限 = 2。极限只承诺"附近的趋势"，从不承诺"点本身"。
连续 ⇒ 可导没有跳变就是光滑的反例 |x| 在 0 处连续但不可导；x^(2/3) 连续、竖直切线、导数无穷。可导 ⇒ 一定连续，反过来不成立。
面积永远为正积分 = 曲线下面积曲线在 x 轴下方时积分为负。"面积"是助记说法，严格说是有向面积，也可能是"曲线与 x 轴之间的几何面积"。
积分的 ∫dx 是"无穷小"dx = 0dx 是一个符号，代表"一点点 x"，是记号约定。它不能单独求值，只有乘上函数才有意义。
先求导再积分就对得上中间可以随便来只有定积分满足 ∫ab f′ = f(b) − f(a)，前提是 f 在区间上连续。不定积分还要带 "+C"，因为原函数不唯一。
链式法则忘记乘内导(x²)′ = 2x 就够了若内层是 g(x)=sin x，则 (sin(x²))′ = 2x·cos(x²)。漏乘内导是最常见计算错误，自检口诀：每层都求导，一路乘下去。
泰勒展开"处处精确"有限项就是原函数有限项只在展开点附近有效（局部逼近）。离展开点越远误差越大——这就是余项红色区域。工程上只在"离得足够近"时用它。
洛必达无脑用看到 0/0 就洛必须先确认是 0/0 或 ∞/∞ 且该点附近可导、导数之比极限存在（需左右极限分别存在且相等）。x²/x 是 0/0 但极限就是 0（还除了一定义域限制），直接洛会丢失 x≠0 的条件。

🔁 三组必须分清

微分 df：切线在 dx 上的"直线抬升量"，是线性近似 f(x+dx) ≈ f(x)+f′(x)dx。
导数 dy/dx：切线斜率，本质是比值。
积分 ∫：无穷多个微分的累加。
三者关系：Δy ≈ dy = f′(x)dx，∫dy = Δy。

🧮 何时用哪个

求瞬时变化率 / 优化 / 建模 → 导数。
求累积量 / 面积 / 质心 / 平均值 → 积分。
已知初始状态的运动规律 → 先列微分方程，再积分。
判断口诀：看到"每单位""瞬时""速率/最陡"用导数；看到"总共""累计""平均"用积分。
