## 这是什么？

一堆**双击就能打开、点开就能玩**的知识可视化页面。每个页面都是一个**单文件 HTML**——没有安装、没有构建、没有后端，浏览器打开即用：拖一拖、点一点、拉一拉滑杆，把抽象的公式与遥远的历史变成看得见、摸得着的东西。

> 全部由 AI 辅助创作 + 人工反复校对打磨。内容力求准确，发现错误欢迎提 Issue 指正。

## 使用方式

| 方式 | 做法 |
|------|------|
| 🌐 在线游玩 | 点开上方链接或仓库内任意 `.html`（GitHub Pages 托管） |
| 💾 本地打开 | 下载任意 `.html` 文件，双击即用；主体完全离线可用* |
| 📎 教学嵌入 | 页面均为独立文件，可直接用 iframe 嵌入自己的讲义或网站 |

\* 个别页面的 3D 演示会按需从 CDN 加载 three.js 等库，断网时自动降级为 2D / 静态方案。

## 页面设计特点

- 🧩 **单文件**：HTML / CSS / JS 全内联，方便随身携带与转发
- 🎨 **双主题**：每个页面都有日间 / 夜间模式
- 📱 **移动端适配**：手机上也能正常操作
- 🔗 **深链分享**：支持带状态的分享链接（如 `math-atlas.html#f=...`）
- 🧭 **无追踪、无后端**：学习进度等偏好仅存本地浏览器
